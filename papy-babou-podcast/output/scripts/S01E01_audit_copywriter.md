## 3. Arc émotionnel — 9/10

Arc exemplaire pour un épisode d'ouverture :
1. **Arrivée joyeuse** (bottes étoiles, jardin)
2. **Curiosité** ("c'est qui qui a fait les fleurs ?")
3. **Émerveillement progressif** (les 7 jours, chaque jour une merveille)
4. **Tendresse** (Papy prend les enfants contre lui, Mamie et les sablés)
5. **Morale** (le monde est un cadeau)
6. **Ouverture** (le bébé qui arrive = cadeau aussi)
7. **Teasing** (jardin d'Éden, l'arbre interdit)

Le rythme des 7 jours avec les chimes crée une cadence quasi musicale — les enfants auditeurs pourront compter les jours.
